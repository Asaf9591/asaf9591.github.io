📌 What Is CodeTrackr?

CodeTrackr is a self-hosted web app that records how long you spend coding. It tracks your activity across different projects, programming languages, and code editors. You get a live dashboard that shows where your time goes. No programming skills are needed to set it up or use it.

Key idea: CodeTrackr runs on your own computer. You control the data. It tracks your coding time automatically.

👤 Who Is This For?

This app is for developers, freelancers, students, and anyone who writes code. If you want to understand how you spend your time, CodeTrackr helps you see the facts. It works for solo developers and small teams.

⚙️ Features

  • Live Dashboard: See your coding time update in real time. No need to refresh.
  • Per-Project Tracking: Know which projects get the most attention.
  • Language Breakdown: View time spent per programming language (Python, JavaScript, C#, etc.).
  • Editor Support: CodeTrackr works with VS Code, JetBrains, Sublime Text, and more.
  • Self-Hosted: Your data stays on your machine. No cloud uploads.
  • Simple Setup: One download, one run. No configuration needed.
  • Export Data: Download your logs as CSV for further analysis.

💻 System Requirements

CodeTrackr runs on Windows 10 or newer. It needs about 100 MB of free disk space. Your computer must have a 64-bit processor. An internet connection is only needed for the initial download and for accessing the dashboard from other devices on your network.

Note: CodeTrackr does not require Python, Node.js, or any programming language installed. It includes everything it needs.
