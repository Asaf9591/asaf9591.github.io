Comienza en 3 Pasos

Instala VORTEX y ejecuta tu primera auditoría en minutos

1

Instala el binario

pip install vortex

O descarga el binario standalone desde GitHub Releases

2

Ejecuta el escaneo

vortex http://mi-app.com --username admin

El crawler descubrirá la superficie de ataque automáticamente

3

Analiza el reporte

open /opt/vortex/reporte/informe_*.html

Visualiza hallazgos priorizados por severidad y acción sugerida
